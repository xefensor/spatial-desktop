# UI and UX notes

## Native panels and widgets — 19 October 2026

One panel engine owns desktop geometry. Apps, Files, Assistant and individual system tools are live widgets; the earlier Areas docking, resize and independent rail engines are retired.

Compact and expanded panels keep the same grouping. Quick launch and Background remain visible; Parked alone scrolls. Icons open existing live content beside the panel. Keep expanded pins it without losing drafts or controls.

Arrangement starts with **right-click panel → Edit layout**. Panels and widgets have no headers or panel footers. Widgets move only during editing; panels move through the Panels picker and resize at their borders. Spacers are repeatable widgets. Cancelling restores the previous arrangement.

The default layout gives Apps the left column, keeps time readable and groups Overview with the lower system icons. Files and Assistant start in a narrow right panel. System controls and popups use glass; app content uses opaque ABS.

Guide and Settings describe current controls. Saved lesson IDs remain compatible. Automated checks cover actions, ownership, live nodes, overflow, displays and Guide targets. Browser appearance is verified separately when browser tooling is available.
