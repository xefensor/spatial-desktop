# Live browser smoke test — 20 October 2026

Tested the public GitHub Pages demo in a fresh Chrome session at 1363 × 936. These are direct browser interactions and visual observations, supplementing the automated checks recorded on 19 October.

## Completed scenarios

| Scenario | Observed result |
| --- | --- |
| Fresh Guide | System toggle off/on completed its task; Apps unlocked; Overview launched Note Editor; search launched Firefox; Shift-click created a separately numbered Note Editor window. |
| Guide reload and exit | Reload resumed the completed independent-window task. Leaving the introduction and choosing Explore the demo loaded the populated desktop. |
| Expanded Apps | Parking File Browser produced one Parked card. Unpark restored the window and removed the card. |
| Compact Apps | The parked icon stayed separate from Quick launch. Its right-click menu identified the actual File Browser window; Show window restored it. |
| Files and Assistant | Both compact popups opened. Escape closed Assistant; its draft survived close/reopen, reload, Keep expanded and panel hiding/recovery. |
| Layout editing | Right-click opened Edit layout. Two independent Spacers could be added. Dragging Clock into the right panel succeeded. Keyboard resizing changed the left panel from 232 to 248 pixels. |
| Layout persistence | Reload retained both Spacers, the moved Clock and compact left panel. Switching to Work showed its independent default layout; returning to General restored the custom layout and draft. |
| Recovery and Calendar | Hidden right panel could be recovered through Choose widgets → Show Right panel. Clock opened Calendar after leaving Overview. |

## Issues found and corrected

1. **Pointer resizing in Edit layout:** widget Edit covers painted above panel borders and intercepted their pointer input. The panel body now establishes a local content stacking context beneath both thickness and length resize handles. Regression coverage checks this relationship on every edge, compact and expanded, including a Spacer.
2. **Briefly disabled controls after Overview:** closing Overview updated the native modal state, but compact launchers, Clock and Overview's expanded state could wait for the next one-second refresh. Overview now refreshes panel projections immediately after its own state is updated. The regression exercises both Work and General with no timer or animation-frame flush.

This is a desktop Chrome smoke test, not cross-browser or mobile certification. It exercises the initial Guide chapters rather than every lesson, and does not verify native OS integration or an external AI service.
