# Edge-case regression pass — 21 October 2026

Baseline: `137b673`. This pass targets interrupted gestures, delayed actions,
concurrent Assistant activity and expired Guide display sessions.

| Reproduction | Correction | Regression coverage |
| --- | --- | --- |
| Release a panel/widget drag outside the page, then return without the mouse button held. | Cancel the preview, restore the original layout and release drag UI. Hidden tabs also cancel a gesture. | `check-panel-desktop.cjs`: panel resizing, panel movement, widget movement, drafts and saved state. |
| Close Pack/Import before its opening frame, or immediately reopen it. | Old frames, close timers and focus callbacks cannot reopen, hide or take focus from a newer dialog. | `check-ui-refinements.cjs`: controlled timer/frame order and focus ownership. |
| Queue a Project action during a desktop animation, then switch Workspace or Project column. | Delayed activation, closure and removal stay bound to their initiating context and intended Project. | `check-desktop-columns.cjs`: mismatched Workspace/column and changed Project identities. |
| Request an app during an animation, then navigate to another Workspace, Project or desktop. | Discard the stale launch instead of opening it in the new destination. | `check-apps-quick-launch.cjs`: changed destinations and an unchanged successful destination. |
| Type in one display while Assistant adds a reply or source to the same chat on another. | Merge draft and content updates independently; keep existing chat data, intentional draft clearing and source removal. | `check-ai-chats.cjs`: both arrival orders, reload and legacy chat snapshots. |
| Start overlapping file drops with only one attachment slot left. | Recheck capacity after asynchronous storage/text reads; discard the rejected upload's bytes without a false success or history entry. | `check-ai-chats.cjs`: delayed storage, delayed text and switching chats during completion. |
| Keep or reopen an old Guide companion after its owner leaves or starts a new practice session. | Revalidate the owner session before storage access; stale children cannot read, write or remove the current practice data. | `check-spatial-guide.cjs`: old URLs, owner exit, replacement sessions, malformed state and missing tokens. |

Assistant content-to-content conflicts still use the existing last-writer rule.
The chat correction separates draft typing from content updates; it does not
introduce collaborative text editing.

Existing saved layouts, Guide lesson identifiers, project data and chat history
remain compatible. No retired Areas interface is restored.
