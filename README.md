# Spatial Desktop

A tactile, project-centred computing environment.

This repository is being populated with the current desktop prototype and all 153 saved source versions. The import preserves each version's exact source tree in chronological Git commits. Original commit IDs and timestamps are recorded separately; the original Git history is also included as a Git bundle.

Live demo: https://spatial-desktop.xefensor.chatgpt.site

## Run locally

```sh
python3 -m http.server 8000 --directory dist
```

Open http://localhost:8000 and use your browser's fullscreen mode.

## About the prototype

This is a browser simulation of a desktop environment. Its apps, files and system services are examples, not native OS integrations.
